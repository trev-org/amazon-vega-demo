# Vega Sample Package

The Vega Sample Package is a TypeScript reference implementation demonstrating two core Vega OS APIs for Fire TV applications:

- **Content Launcher API** — Integrate with the Fire TV home launcher and Alexa voice commands for content search and playback
- **Media Controls API** — Provide unified media control across diverse input modalities (remote, voice, touch)

## What is Vega OS?

Vega OS is Amazon's operating system for Fire TV devices. It provides APIs that enable streaming apps to deeply integrate with the Fire TV platform, offering users seamless content discovery and playback experiences through voice, remote control, and touch interfaces.

## Use cases

### Content Launcher API

- **Voice-activated playback** — "Alexa, watch Seabound on MyApp"
- **Content search** — "Alexa, find comedy movies on MyApp"
- **Episodic content** — "Alexa, play season 1 episode 5 of The SeaShow"
- **Deep linking** — Launch specific content from the Fire TV home screen

### Media Controls API

- **Unified playback control** — Handle play, pause, seek, and skip commands from any input source
- **Picture-in-picture** — Manage multiple concurrent media sessions
- **Session management** — Track playback state, position, and capabilities
- **Endpoint discovery** — Register your app as a media provider for platform-wide control

## Architecture

The package is organized into two independent modules:

```
vega-sample-package/
├── content-launcher/     # Content Launcher API implementation
│   ├── types.ts         # Type definitions and interfaces
│   ├── content-launcher.ts  # Processing logic
│   └── examples/        # Usage examples
└── media-controls/      # Media Controls API implementation
    ├── types.ts         # Type definitions and interfaces
    ├── session-manager.ts   # Session lifecycle management
    ├── discovery.ts     # Endpoint discovery
    └── examples/        # Usage examples
```
